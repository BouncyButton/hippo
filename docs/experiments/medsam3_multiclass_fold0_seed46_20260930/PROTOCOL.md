# MedSAM3 three-class pilot: fold 0, seed 46

Requested 30 September 2026 to correct the earlier binary-union experiment. Preserve the previous five support volumes (156, 197, 260, 335, 370) and 46 held-out fold-0 volumes. All arms start from the same original medical LoRA adapter. Seed 46, 200 AdamW updates, two adjacent-slice pairs per update, matched schedule, learning rates and 20-update constraint ramp. This is a new exploratory pilot, not a rerun of the earlier binary task.

Labels remain background=0, anterior=1, posterior=2. Each image plane supplies two separate native SAM3 queries, `anterior hippocampus` and `posterior hippocampus`, supervised by their respective class masks. Background pixels are negative examples for both queries. The native objective averages the two class-query losses and both planes; there are 800 slice presentations and 1,600 class-query presentations per arm. No ground-truth box or point is supplied as an input prompt.

For each class prompt, differentiable mask × query × presence probabilities are combined across instances as in the previous semantic projection. Normalize `[0, logit(p_anterior), logit(p_posterior)]` with log-softmax to obtain mutually exclusive background/anterior/posterior probabilities. Inference uses the identical projection and three-class argmax, without instance thresholding, NMS or postprocessing. This explicitly differs from the earlier thresholded binary inference.

Baseline uses native supervised SAM3 losses. Bands adds the equal-class mean of balanced inner/outer BCE for each of the three class masks. Bands+edge also adds the equal-class mean signed-face residual loss. The two-step native 3D bands therefore include the internal A/P interface. Adjacent-plane sampling, native-volume denominators and no wraparound faces are retained. Calibrate coefficients once on support data at initialization, using the existing median gradient-ratio target 0.1 and p95 cap 0.5; reuse exactly across arms.

Save final adapters, three-channel probabilities, and discrete labels for all five training volumes and 46 validation volumes. Report per-class Dice, FP/FN/TP, 3×3 confusion matrices, A→P and P→A swaps, and mean anterior/posterior Dice as the primary metric. Save all arm predictions before scoring validation labels. Training metrics are resubstitution measurements and are separate from validation.

Checks: original split and image/label hashes; BG/A/P presence in support volumes; identical initial adapters, slice schedules and learning rates; unchanged frozen parameters; finite nonzero constraint gradients; valid normalized three-class probabilities; saved-mask confusion counts and output hashes. CPU regression tests explicitly require A/P swaps to remain errors when union segmentation is perfect and require classwise constraints to penalize them. GPU preflight exercises label-free inference before calibration/training.
