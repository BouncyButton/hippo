# Reporting audit

Recorded while 42/48 priors were complete, before assessment scoring.

The frozen evaluator stores advancement booleans only for deformable fusion,
deformable graph fusion, and deformable A/P fusion. The written protocol does
not restrict the A/P criterion to the deformable family. The report therefore
applies the same written criteria to **every** locked atlas family, including
centered and affine, in `all_family_gate_audit.json`. The registration, fusion,
calibration choices, cohort, and thresholds are unchanged. No assessment
outcomes were read to motivate this audit. Development advancement must follow
this complete audit rather than silently excluding a qualifying affine arm.
